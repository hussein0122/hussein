# ShortsPilot AR 🇪🇬

أتمتة إنتاج فيديوهات YouTube Shorts عربية باستخدام PurffleShorts، مع Gemini API للسكريبتات، وEdge TTS للصوت، ولقطات مرخّصة من Pexels أو Pixabay، ثم مونتاج عمودي تلقائي.

## الحالة الحالية

- ملفات المشروع الأساسية موجودة.
- تم تجهيز Workflow **يدوي تجريبي فقط** لإنتاج فيديو واحد ورفعه بخصوصية `private`.
- لا يوجد نشر عام أو جدول تلقائي مفعل في هذه المرحلة.
- الردود على التعليقات متوقفة افتراضيًا.
- لا توجد مفاتيح API أو ملفات OAuth محفوظة في المستودع.

> إنشاء الملفات وتجهيز Workflow لا يعني أن القناة متصلة أو أن فيديو تم إنتاجه أو رفعه. يلزم إعداد الأسرار ثم تشغيل الاختبار ومراجعة الناتج.

## مكونات الإنتاج

1. **Gemini API** يختار الفكرة ويكتب السكريبت وبيانات الفيديو. استخدم مفتاح Google AI Studio على الطبقة المجانية فقط.
2. **Edge TTS** ينشئ تعليقًا صوتيًا عربيًا.
3. **Pexels / Pixabay** يوفّران لقطات مرئية. مفاتيح API الخاصة بهما مجانية وفق شروط كل مزود.
4. **PurffleShorts + FFmpeg** يركّبان المشاهد والصوت والترجمة والمؤثرات في فيديو 9:16.
5. **YouTube Data API** ترفع الفيديو كخاص في الاختبار.

Gemini النصي لا يولّد ملف الفيديو النهائي بنفسه؛ محرك الإنتاج يجمع الأصول ويصنع الفيديو.

## الإعداد الآمن

### 1. مفاتيح الخدمات المجانية

- أنشئ مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/).
- أنشئ مفتاح Pexels من [Pexels API](https://www.pexels.com/api/).
- أنشئ مفتاح Pixabay من [Pixabay API](https://pixabay.com/api/docs/).

أضف المفاتيح إلى GitHub Repository → Settings → Secrets and variables → Actions:

| Secret | الاستخدام |
|---|---|
| `GEMINI_API_KEY` | Gemini API |
| `PEXELS_API_KEY` | لقطات Pexels |
| `PIXABAY_API_KEY` | لقطات Pixabay |
| `YT_TOKEN_JSON_B64` | تفويض YouTube بصيغة Base64 |

يلزم مفتاح مرئي واحد على الأقل (Pexels أو Pixabay). لا تستخدم مفاتيح مدفوعة ولا تفعّل فوترة Gemini. حدود الطبقة المجانية قد تتغير؛ عند تجاوزها يجب أن يفشل التشغيل بدل التحول إلى خدمة مدفوعة.

### 2. تفويض YouTube

1. أنشئ مشروعًا في Google Cloud وفعّل YouTube Data API v3.
2. أنشئ OAuth Client من نوع Desktop وامنح القناة صلاحية الرفع.
3. أكمل التفويض محليًا عبر PurffleShorts لإنشاء `token.json`.
4. حوّل محتوى الملف إلى Base64 واحفظه كـ GitHub Secret باسم `YT_TOKEN_JSON_B64`.

لا ترفع `token.json` أو ملف OAuth أو أي مفتاح إلى GitHub، ولا ترسله في المحادثة.

### 3. فحص Gemini وتشغيل الفيديو التجريبي

من GitHub → Actions → **Arabic Shorts - safe test** → Run workflow. قبل أي إنشاء فيديو، يشغّل الـ Workflow فحصًا صغيرًا لمفتاح Gemini والموديل `gemini-2.5-flash` دون طباعة المفتاح أو محتوى الاستجابة. نجاح الفحص يثبت أن المفتاح والموديل يستجيبان وقت التشغيل فقط؛ ولا يثبت توفر حصة مجانية مستقبلًا.

هذا الاختبار:
- ينتج فيديو واحدًا فقط.
- يرفع الفيديو بخصوصية `private`.
- يحفظ ملف الفيديو والبيانات كـ Artifact لمدة 7 أيام.
- لا ينشر الفيديو للعامة ولا يفعّل الردود على التعليقات.

راجع الفيديو والصوت والنطق والترجمة واللقطات قبل أي تشغيل متكرر.

## الانتقال إلى الإنتاج اليومي

بعد الموافقة على جودة الفيديو، نحدّث Workflow بشكل منفصل لتفعيل ثلاثة تشغيلات يوميًا وفق توقيت `Africa/Cairo`، ونغيّر خصوصية النشر فقط بموافقة صاحب القناة. لا يتم تفعيل الجدول تلقائيًا بمجرد إعداد مفاتيح الاختبار.

## التكلفة والحدود

- لا نستخدم Veo أو توليد فيديو مدفوع في هذه الخطة.
- Gemini API وPexels وPixabay لها حدود وشروط مجانية تتغير؛ لا يوجد ضمان لاستمرار المجانية أو توافر الحصة.
- GitHub Actions المجاني له حدود استخدام، وYouTube API لها حصص يومية.
- لا يوجد ضمان للمشاهدات أو تحقيق الربح.
- أي خطوة تتطلب دفعًا أو تفعيل فوترة تتوقف لحين موافقة صريحة.

## الرد على التعليقات

الردود الآلية متوقفة. لا تفعّل `AUTO_REPLY_ENABLED=true` قبل إعداد تخزين دائم لمنع تكرار الردود عبر تشغيلات GitHub Actions المنفصلة، ومراجعة الردود وسياسة القناة.
