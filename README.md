# ShortsPilot AR 🇪🇬

مشروع أتمتة قناة YouTube Shorts باللغة العربية، مبني كطبقة تشغيل فوق [PurffleShorts](https://github.com/Chamanrajragu/purffle-shorts) مفتوح المصدر.

## الحالة الحالية
- إعداد التشغيل الآلي لإنتاج فيديو واحد في كل تشغيل، بثلاثة مواعيد يومية.
- إعداد اللغة العربية، مقاس 9:16، وتوقيت القاهرة.
- Workflow على GitHub Actions.
- وحدة مستقلة للردود الآلية على التعليقات مع حدود يومية ومنع التكرار.
- لا تُرفع أي مفاتيح أو ملفات OAuth إلى Git.

> **مهم:** إنشاء الملفات لا يعني أن القناة أصبحت متصلة أو أن فيديو نُشر. التشغيل الفعلي يتطلب إعداد أسرار GitHub وتفويض Google/YouTube، ثم اختبارًا حقيقيًا.

## الإعداد

1. من Google Cloud أنشئ OAuth Client من نوع Desktop، فعّل YouTube Data API v3، ونزّل ملف OAuth.
2. شغّل PurffleShorts محليًا مرة واحدة لإتمام تفويض YouTube وإنشاء token صالح للرفع.
3. خزّن محتوى ملف التوكن بصيغة Base64 في GitHub Actions Secret باسم `YT_TOKEN_JSON_B64`. لا تضعه في المستودع.
4. أضف أسرار النموذج التي تختارها:
   - `LLM_API_KEY` (مثلاً مفتاح مزود متوافق مع OpenAI)
   - `LLM_PROVIDER` و`LLM_MODEL` كـ Variables أو Secrets حسب المزود.
5. أضف `YT_CLIENT_SECRETS_JSON_B64` عند الحاجة لإعداد OAuth داخل بيئة التشغيل.
6. للردود الآلية، أنشئ تفويضًا منفصلًا بصلاحية `https://www.googleapis.com/auth/youtube.force-ssl`، ثم خزّن التوكن Base64 في `YT_COMMENTS_TOKEN_JSON_B64`.
7. فعّل Actions في المستودع.

## إعدادات القناة

الافتراضي: العربية، موضوعات متنوعة، 3 فيديوهات يوميًا، أوقات 09:00 و14:00 و19:00 بتوقيت القاهرة، وخصوصية الرفع `private` حتى يتم اختبار المحتوى. غيّرها بعد مراجعة الجودة.

## التشغيل المحلي

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## الرد على التعليقات

الردود معطلة افتراضيًا. فعّل `AUTO_REPLY_ENABLED=true` بعد مراجعة سياسة القناة. البوت:
- يرد مرة واحدة فقط على كل تعليق ويحفظ المعرفات في SQLite.
- يضع حدًا يوميًا للردود.
- يتجنب الروابط والرسائل المكررة وبعض أنماط الإساءة/السبام.
- يستخدم ردودًا قصيرة ومحايدة، ولا يدّعي تقديم معلومات مؤكدة.

## تنبيهات مهمة
- GitHub Actions المجاني له حدود استخدام، ولا يضمن تشغيلًا دائمًا 24/7.
- واجهة YouTube API لها حصص يومية، وقد يتوقف الرفع عند نفادها.
- لا يوجد ضمان للمشاهدات أو تحقيق الربح. راجع كل فيديو والتزم بسياسات YouTube الخاصة بالمحتوى الأصلي والمحتوى المصطنع.
- لا ترفع `.env` أو ملفات التوكن أو مفاتيح API إلى GitHub.
